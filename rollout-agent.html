🔧 Music Release Metadata Standard ▶

Core IDs

ISRC per track · UPC per release · explicit flag · release date · label · original release date.

Credits & Splits

Writers, publishers, producers — with publishing splits %. Missing splits = delayed or misrouted royalties.

DSP Fields

Spotify Canvas (3–8s), Apple lyrics, YouTube Music Art Tracks, Amazon HD, TikTok sound start date.

Assets

3000×3000 cover (no upscaled), 16:9 video, clean instrumental + acapella stems for remix/UGC.

Delivery

Distributor upload ≥ 3 weeks out. Metadata locked by T-14. Pitching windows close before street date.

Clearance

Sample clearances, feature agreements, master use licenses — in writing before distribution.
